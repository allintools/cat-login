# 猫在 · 49 帧鼠标跟随登录页

纯静态登录页交互原型。原创奶油猫按鼠标或触屏方向，在 7×7 共 49 个姿态之间平滑转头；页面同时演示密码聚焦回避、方向面板和本地登录状态切换。

## 运行

直接双击 `index.html`，或双击 `打开原型.bat`。无需安装、构建或联网。

需要本地 HTTP 时（已安装 Node.js）：

```bash
node serve.cjs
```

打开 http://127.0.0.1:4173 。端口占用时，在 PowerShell 中执行 `$env:PORT=4174; node serve.cjs`。

## 功能

- 49 张独立、统一 600×600 的原创 SVG 帧，7 行 × 7 列，全部预加载并解码。
- 指针在页面任意位置移动；以猫眼位置为基准，按到四侧视口边缘的距离归一化，四角都能到达。
- 触屏在猫咪区域按住拖动，使用 Pointer Capture，移出区域继续跟随；松手、取消或离开窗口后延迟 220ms 回中。
- 指针经约 45ms 指数平滑；7×7 帧索引每格边界设置 0.12 格迟滞，避免边界抖动。
- 默认矢量猫从 49 张关键姿态提取 11 个变化属性，实时插值头部、瞳孔、高光与口鼻的几何坐标。每时刻只显示一只猫，不对整图做透明叠加，因此没有轮廓拖影。
- 安静陪伴开关与系统 `prefers-reduced-motion` 均关闭时间缓动，保留方向迟滞。
- 点击“方向面板”检查 49 帧，点击某格锁定预览；“恢复跟随”解除锁定。猫咪区域或方向面板支持方向键，Escape 恢复跟随。
- 密码框聚焦时猫咪看向左上角；支持显示/隐藏密码。有效邮箱 + 至少 6 位密码可进入本地欢迎状态，也可免登录体验。
- 单张素材出错时使用二维距离最近的可用帧，失败格不可点击，加载超过 10 秒计为失败；全部失败显示错误提示。
- 页面后台暂停动画；空闲时停止动画循环。无 Canvas 时回退到普通图片逐帧显示。

## 素材与替换

当前角色是为本原型绘制的原创程序化矢量猫，不是对任何参考图的复刻。`assets/contact-sheet.svg` 可独立打开查看 49 帧总览，`assets/manifest.json` 包含全部坐标与路径。

编号从 0 开始，`index = row * 7 + col`：

| 方向 | 左上 | 正上 | 右上 | 正左 | 正中 | 正右 | 左下 | 正下 | 右下 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| index | 0 | 3 | 6 | 21 | 24 | 27 | 42 | 45 | 48 |

行从上到下，列从左到右。猫的目光指向屏幕对应方向，不做镜像翻转。

替换为其他角色：

1. 准备 49 张同尺寸、同构图、透明背景的 PNG/WebP/SVG，保持身体和眼睛基准位置一致。
2. 按行优先顺序命名 `cat-00` 到 `cat-48`，放入 `assets/frames/`。替换后先将 `app.js` 顶部 `USE_VECTOR_FRAMES` 设为 `false`；使用 PNG/WebP 时同步修改 `FRAME_URLS` 的扩展名、`index.html` 的静态居中图和 favicon。
3. 当前素材眼睛基准为画面 x=50%、y=44%。眼睛位置不同时，调整 `app.js` 中 `point()` 的 `.5`、`.44`，映射算法无需改动。
4. 新素材须为正方形，或自行调整 Canvas 的等比适配，并同步更新 `manifest.json` 与总览图。

如果新的 49 张 SVG 元素结构、属性和绘制顺序完全一致，只改变几何数值，可执行 `node tools/generate-vector.cjs` 重新生成 `vector-frames.js`，再开启 `USE_VECTOR_FRAMES`。结构不兼容时生成器会报错。`node tools/generate-assets.cjs` 可重新生成默认 49 张素材与总览，会覆盖当前同名 SVG。

## 目录结构

```
cat-login/
  index.html            页面入口
  style.css             布局与视觉样式
  app.js                指针映射、渲染、表单交互
  mapping.js            方向量化与平滑工具
  vector-frames.js      49 帧几何插值数据
  assets/
    frames/cat-00.svg   49 张方向帧
    contact-sheet.svg   49 帧总览
    manifest.json       素材清单
  tools/                素材与几何数据生成脚本
  check.cjs             逻辑与素材检查
  serve.cjs             可选本地静态服务器
  DESIGN.md             颜色、字体与组件规范
```

## 检查

```bash
node check.cjs
```

检查 49 帧唯一性、全部格点映射、边界、迟滞、归一化、平滑、缺帧回退，以及矢量几何是否与原始关键姿态一致。

浏览器控制台可执行 `catPrototype.getState()` 查看加载、当前帧和跟随状态，不包含表单数据。

## 范围

这是登录交互原型。提交只切换本地欢迎界面，未连接真实认证或找回密码服务，不发送或保存账号密码；进入欢迎界面时清空两项输入。真实上线需另接认证后端。
